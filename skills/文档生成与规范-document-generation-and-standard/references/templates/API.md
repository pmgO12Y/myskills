## 3. 接口详情

### 3.1 [接口名称]

**请求：**
- 方法：POST
- 路径：`/api/orders`
- Headers：...

**请求参数：**

| 字段 | 类型 | 必填 | 说明 | 示例 |
|------|------|------|------|------|
| order_id | string | 是 | 订单ID | "ORD001" |

**响应参数：**

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| code | int | 状态码 | 200 |

**错误码：**

| 错误码 | 含义 | 触发条件 |
|--------|------|----------|
| 40001 | 参数缺失 | 必填字段为空 |

**调用示例：**

```json
// 请求
{
  "order_id": "ORD001"
}

// 响应
{
  "code": 200,
  "data": {}
}
```
