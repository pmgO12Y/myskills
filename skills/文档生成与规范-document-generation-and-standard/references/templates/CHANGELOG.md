# CHANGELOG 规范

## 更新时机

产生**用户可见的功能变动**时必须更新（内部重构、测试、日志文件修改豁免）

## 格式

```markdown
## [YYYY-MM-DD]
### 新增 (Added)
- [功能点] @PRD_v2.1.0
### 修复 (Fixed)
- [修复内容] @PRD_v2.0.1
### 变更 (Changed)
- [变更内容] @MRD_v1.1.0
### 废弃 (Deprecated)
- [废弃内容]
```

## 关联文档标注规则

- 每个功能点、修复或变更条目末尾，使用 `@文档类型_v版本号` 格式标注关联的 BRD/MRD/PRD 版本
- 示例：`@PRD_v2.1.0`、`@MRD_v1.0.0`、`@BRD_v1.2.0`
- 若一个条目涉及多份文档，可并列标注：`@PRD_v2.1.0` `@MRD_v1.1.0`
