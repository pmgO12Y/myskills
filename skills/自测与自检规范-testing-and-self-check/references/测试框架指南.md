# 测试框架指南

各主流编程语言的推荐测试框架、安装命令和最小示例。

---

## JavaScript / TypeScript

| 框架 | 推荐场景 | 安装命令 |
|------|----------|----------|
| **Jest** | 通用首选，支持快照、Mock、Coverage | `npm install --save-dev jest` |
| **Vitest** | Vite 项目首选，极速、兼容 Jest API | `npm install --save-dev vitest` |
| **Mocha + Chai** | 需要灵活配置的大型项目 | `npm install --save-dev mocha chai` |
| **Playwright** | E2E 测试 | `npm install --save-dev @playwright/test` |

### Jest 最小示例

```javascript
// sum.js
function sum(a, b) {
  return a + b;
}
module.exports = sum;

// sum.test.js
const sum = require('./sum');

describe('sum', () => {
  it('should return correct sum for positive integers', () => {
    expect(sum(2, 3)).toBe(5);
  });

  it('should handle zero correctly', () => {
    expect(sum(0, 0)).toBe(0);
  });

  it('should throw error for non-number inputs', () => {
    expect(() => sum(null, 3)).toThrow();
  });
});
```

### 运行测试 + 查看覆盖率

```bash
npx jest --coverage
```

## Python

| 框架 | 推荐场景 | 安装命令 |
|------|----------|----------|
| **pytest** | 通用首选，简洁强大 | `pip install pytest pytest-cov` |
| **unittest** | 标准库，无需安装 | 内置 |

### pytest 最小示例

```python
# sum.py
def sum(a, b):
    if not isinstance(a, (int, float)) or not isinstance(b, (int, float)):
        raise TypeError("Inputs must be numbers")
    return a + b

# test_sum.py
import pytest
from sum import sum

def test_sum_positive_integers():
    assert sum(2, 3) == 5

def test_sum_zero():
    assert sum(0, 0) == 0

def test_sum_invalid_input():
    with pytest.raises(TypeError):
        sum(None, 3)
```

### 运行测试 + 查看覆盖率

```bash
pytest --cov=src --cov-report=term-missing
```

## Java

| 框架 | 推荐场景 | 安装方式 |
|------|----------|----------|
| **JUnit 5** | 单元测试标准 | Maven/Gradle 依赖 |
| **Mockito** | Mock 框架 | 配合 JUnit 使用 |
| **AssertJ** | 流式断言 | 配合 JUnit 使用 |

### JUnit 5 最小示例

```java
import org.junit.jupiter.api.Test;
import static org.assertj.core.api.Assertions.*;

class CalculatorTest {
    @Test
    void shouldReturnSumWhenGivenTwoPositiveIntegers() {
        Calculator calc = new Calculator();
        assertThat(calc.add(2, 3)).isEqualTo(5);
    }

    @Test
    void shouldThrowExceptionWhenGivenNull() {
        Calculator calc = new Calculator();
        assertThatThrownBy(() -> calc.add(null, 3))
            .isInstanceOf(IllegalArgumentException.class);
    }
}
```

### Maven 运行测试 + 覆盖率

```bash
mvn test
mvn jacoco:report
```

## Go

| 框架 | 推荐场景 | 说明 |
|------|----------|------|
| **testing** | 标准库，Go 首选 | 内置，无需安装 |
| **testify** | 增强断言 + Mock | `go get github.com/stretchr/testify` |

### Go testing 最小示例

```go
// sum.go
package calc

func Sum(a, b int) int {
    return a + b
}

// sum_test.go
package calc

import "testing"

func TestSum(t *testing.T) {
    tests := []struct {
        name     string
        a, b     int
        expected int
    }{
        {"positive integers", 2, 3, 5},
        {"zeros", 0, 0, 0},
        {"negatives", -1, -2, -3},
    }

    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            result := Sum(tt.a, tt.b)
            if result != tt.expected {
                t.Errorf("Sum(%d, %d) = %d, want %d", tt.a, tt.b, result, tt.expected)
            }
        })
    }
}
```

### 运行测试 + 查看覆盖率

```bash
go test -cover ./...
go test -coverprofile=coverage.out ./...
go tool cover -html=coverage.out
```

## 覆盖率报告解读

| 指标 | 含义 | 合格线 |
|------|------|--------|
| **Statements** | 执行到的语句数 / 总语句数 | ≥ 90%（核心逻辑） |
| **Branches** | 执行到的分支数 / 总分支数 | ≥ 85% |
| **Functions** | 执行到的函数数 / 总函数数 | ≥ 90% |
| **Lines** | 执行到的行数 / 总行数 | ≥ 90% |

> **💡 提示**：覆盖率报告中的红色/未覆盖行是补测试的最佳线索。
