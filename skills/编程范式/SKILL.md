# 编程范式指导

## 概述

为遵循函数式编程（FP）原则的代码编写、审查和重构提供全面指导，涵盖多种语言（JavaScript/TypeScript、Python、Java 等）。

## 何时使用本技能

当用户处理代码且满足以下任一条件时，激活本技能：

- 编写新代码，希望遵循函数式编程原则
- 审查现有代码是否符合函数式规范或纯度要求
- 将命令式或面向对象代码重构为函数式风格
- 讨论或询问纯函数、不可变性、副作用、Monad、函数组合或声明式编程
- 请求包含以下关键词："更函数式"、"FP 审查"、"重构为函数式"、"写函数式的"、"消除副作用"、"使用不可变数据"、"纯函数"、"无副作用"等

## 工作流程

### 步骤 1：识别用户意图

确定三个主要场景中哪个适用：

1. **编写指导** — 用户在编写新代码，希望获得函数式最佳实践
2. **代码审查** — 用户提供代码，希望依据函数式原则进行审查
3. **重构** — 用户希望将现有代码转换为函数式风格

如果意图不明确，可以询问："您是想编写新的函数式代码、审查现有代码，还是将命令式代码重构为函数式风格？"

### 步骤 2：加载参考文档

根据任务类型加载对应的参考文档：

## 场景 1：编写函数式代码

当指导用户以函数式风格编写新代码时：

1. 加载 `references/核心原则.md` 和 `references/语言指南.md`
2. 确定目标语言
3. 从 `语言指南.md` 应用对应的语言特定模式
4. 确保遵循所有核心原则：
   - 函数是纯函数（输出仅依赖于输入）
   - 数据不可变（创建后不修改）
   - 在业务逻辑中避免副作用
   - 优先使用声明式风格（map/filter/reduce 优于循环）
   - 优先使用小的、可组合的函数而非大型单体函数
   - 避免使用 Null/undefined，改用 Option/Maybe 类型
5. 用目标语言提供代码示例

## 场景 2：FP 合规性代码审查

当审查现有代码是否符合函数式编程规范时：

1. 加载 `references/核心原则.md` 和 `references/反面模式.md`
2. 依据 `反面模式.md` 中的反面模式检查清单系统地审查代码
3. 对每个发现的问题：
   - 识别违反的具体原则
   - 引用有问题的代码
   - 解释其为何违反函数式原则
   - 建议修正版本
4. 汇总审查结果，列出哪些原则得到遵守、哪些需要关注

**审查输出结构：**

   - **问题**: 【问题描述】
   - **建议**: 【修正后的代码】

### 总结

| 原则 | 状态 | 备注 |

## 场景 3：重构为函数式风格

当将命令式/面向对象代码重构为函数式风格时：

1. 加载 `references/核心原则.md`、`references/反面模式.md` 和 `references/重构模式.md`
2. 确定目标语言
3. 分析原始代码，分类每个发现的反面模式
4. 为每个问题从 `重构模式.md` 选择适当的重构模式
5. 按以下优先级顺序应用重构：
   - **优先级 1**：提取纯函数并隔离副作用
   - **优先级 2**：用不可变更新替换可变修改
   - **优先级 3**：用声明式操作替换命令式循环
   - **优先级 4**：引入 Option/Result 类型替换 null/基于异常的控制流
   - **优先级 5**：应用函数组合扁平化嵌套调用
6. 展示重构后的代码，并在关键变更处添加内联注释
7. 如果重构范围很大，请增量进行（每次一个函数/模块）

**重构输出结构：**

```
## 重构计划

### 步骤 1：【模式名称】
- **应用位置**：【函数/章节】
- **理由**：【为何使用此模式】
- **结果**：【重构后的代码】

### 最终结果
【完整重构后的代码】

### 变更内容
- 【变更摘要】
```

## 多语言注意事项

始终确定目标语言并加载 `references/语言指南.md` 获取语言特定建议。目前已覆盖的语言：

- **JavaScript/TypeScript**：`const`、展开运算符、`Readonly<T>`、箭头函数、可选链
- **Python**：`tuple`、列表推导式、`dataclass(frozen=True)`、`functools`、生成器表达式
- **Java**：`final`、Stream API、`Optional<T>`、不可变集合、records（Java 16+）
- **C#**：`readonly`、`record`、LINQ、可空引用类型、LanguageExt
- **Go**：值语义、泛型高阶函数、多返回值错误处理、samber/mo
- **C++**：`const`、STL / C++20 Ranges、`std::optional`、`std::expected`、range-v3
- **Rust**：默认不可变、所有权系统、惰性迭代器、`Option<T>` / `Result<T, E>`、rayon
- **Kotlin**：`val` / `data class`、标准库集合操作、可空类型 `T?`、Arrow.kt
- **Swift**：`let` / `struct`（值类型）、标准库高阶函数、`Optional<T>` / `Result<T, Error>`、Bow
- **PHP**：`readonly`（8.1+）、箭头函数 `fn() =>`、数组高阶函数、`?->` 可选链

如果目标语言未在 `语言指南.md` 中覆盖，则应用 `核心原则.md` 中的通用原则，并使用该语言最接近的等价实现。
